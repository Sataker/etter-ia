faq:
  - q: Which systems can be integrated?
    a: 'Any with an API or webhooks — ERP, CRM, e-commerce, tax software, ad platforms, databases. Closed systems without an API need a file-based or interface-level alternative, which is less stable and assessed case by case.'
  - q: What happens when an integration fails?
    a: 'Failures are logged and alerted, with automatic reprocessing. The rule is never to fail silently: data that disappeared without warning costs more than the error itself.'
